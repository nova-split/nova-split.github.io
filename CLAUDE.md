# CLAUDE.md

## Working directory

Always work in `./.tmp/` (relative to the repo root). Put scratch files,
build output, downloads, and intermediate results there, not in the repo tree
or system temp dirs. `.tmp/` is git-ignored and excluded from the Jekyll build.

## Blog posts

To write a new blog post, see the "Blog" section in `README.md` (post format, `blob/` assets, images must be WebP).
